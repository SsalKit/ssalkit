# SsalKit.Generators.Toolkit

SsalKit.Generators.Toolkit is a source-only NuGet package that embeds a small set of internal helper types (`EquatableArray<T>`, `IndentedCodeWriter`, `CSharpNaming`, `HintNameSanitizer`, `DiagnosticDescriptorFactory`) directly into the compilation of Roslyn source generator projects, so generator authors get common boilerplate without shipping or referencing an extra runtime assembly. Full documentation (why, installation, API reference, and known limitations) will be added here in a later pass.
