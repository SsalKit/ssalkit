# SsalKit.Generators.Toolkit — AI contract sheet

A **source-only** toolkit for authoring Roslyn source generators. The package ships `.cs` files as `contentFiles`; they are compiled directly into the consuming generator project as `internal` types. There is **no runtime assembly and no DLL**.

- **TFM:** `netstandard2.0`. **Package dependencies:** none (`DevelopmentDependency=true`, `IncludeBuildOutput=false`).
- **Hard requirement of the consumer:** a `Microsoft.CodeAnalysis` / `Microsoft.CodeAnalysis.CSharp` reference at **4.4.0 or newer**, and `LangVersion` **10 or higher**. Neither is declared as a package dependency, so nothing enforces the floor — an older Roslyn simply fails to build.
- **Namespace:** `SsalKit.Generators.Toolkit` for every embedded type, except the `IsExternalInit` polyfill (`System.Runtime.CompilerServices`, fixed by the compiler).
- This file is written for AI coding agents. Human-facing docs: [`README.md`](README.md) (also `README.ko.md`, `README.ja.md`).

## 1. API surface

All types are `internal` — nothing here appears in the consuming generator's public API.

### Pick the right component

| Requirement | Use |
|---|---|
| Array in a pipeline model that must compare by value | `EquatableArray<T>` |
| Emit source text with indentation tracking | `IndentedCodeWriter` |
| Turn arbitrary text into a C# identifier | `CSharpNaming` |
| Safe `hintName` for `AddSource` | `HintNameSanitizer.Sanitize` |
| Carry a diagnostic through the pipeline without pinning a tree | `DiagnosticInfo` + `LocationInfo` |
| Declare a diagnostic table with a shared prefix/category | `DiagnosticDescriptorFactory` |
| Symbol questions (FQN, namespace, accessibility, genericity, sort) | `SymbolFacts` |
| Report on an attribute application, at the right location | `AttributeLocations` |
| `record`/`init` on `netstandard2.0` | `IsExternalInit` polyfill (shipped) |

### `EquatableArray<T> : IEquatable<EquatableArray<T>>, IEnumerable<T>` — `readonly struct`, `where T : IEquatable<T>`

| Member | Contract |
|---|---|
| `EquatableArray(ImmutableArray<T> array)` | Wraps without copying. |
| `static EquatableArray<T> Empty { get; }` | The non-default empty form. |
| `int Length { get; }` | `0` for a `default` instance. |
| `T this[int index] { get; }` | Indexer over the wrapped array. |
| `ImmutableArray<T> AsImmutableArray()` | `ImmutableArray<T>.Empty` for a `default` instance. |
| `bool Equals(EquatableArray<T> other)` | Element-by-element via `EqualityComparer<T>.Default`. |
| `GetHashCode()` | Combined element hashes, explicitly `unchecked`; `0` for `default`. |
| `operator ==` / `!=`, `implicit operator EquatableArray<T>(ImmutableArray<T>)` | Value semantics. |
| `EquatableArray.Create<T>(ImmutableArray<T>)`, `IEnumerable<T>.ToEquatableArray()` | Static helpers on the non-generic `EquatableArray` class. |

### `IndentedCodeWriter` — `sealed class`

| Member | Contract |
|---|---|
| `IndentedCodeWriter(int indentSize = 4)` | Spaces per level. |
| `void WriteAutoGeneratedHeader(bool suppressWarnings = false)` | `// <auto-generated/>`, optional bare `#pragma warning disable`, `#nullable enable`, blank line. |
| `void Write(string text)` | No trailing break; indents only if at line start. |
| `void WriteLine(string line)` / `void WriteLine()` | Blank lines carry **no** trailing indentation. |
| `void WriteDocLine(string content)` | Prefixes `"/// "`; an empty string writes a bare `///` with no trailing space. |
| `void WriteDocLines(params string[] contents)` / `void WriteDocLines(IEnumerable<string> contents)` | The sequence overload is enumerated exactly once, lazily. `string[]` binds to the `params` overload. |
| `IndentationScope Indent()` | Bare indentation scope, no braces. `using`-disposed. |
| `BlockScope Block(string header)` / `Block(string header, string closer)` | Header, `{`, indent; writes `closer` (default `}`) on dispose. |
| `override string ToString()` | The accumulated source text. |

Line breaks are always `"\n"`, never `Environment.NewLine`.

### `CSharpNaming` — `static class`

| Member | Contract |
|---|---|
| `string ToPascalCaseIdentifier(string? text, string fallback = "Identifier")` | Upper-cases the first letter of each alphanumeric run; `"SsalKit.Sample"` → `"SsalKitSample"`. Prepends `_` if the result would start with a digit. Returns `fallback` for null/empty/no-alphanumerics. |
| `string ToCamelCaseIdentifier(string? text, string fallback = "identifier")` | Pascal segmentation, then lowers the leading upper-case run: `"IOService"` → `"ioService"`, `"Service"` → `"service"`. **May return a reserved keyword.** |
| `string JoinIdentifierSegments(IReadOnlyList<string> segments, char separator = '_')` | Joins already-valid fragments; skips null/empty ones, never emits a leading/trailing/doubled separator. **Never sanitizes.** |
| `string EscapeKeyword(string identifier)` | `"class"` → `"@class"`. Reserved keywords only; contextual keywords (`var`, `nameof`) are left alone. |

### `HintNameSanitizer` — `static class`

| Member | Contract |
|---|---|
| `string Sanitize(string candidate, string suffix = ".g.cs")` | Strips **every** `global::` occurrence, replaces every character outside Roslyn's accepted set with `_` (including the backtick and `+` that are technically allowed), guarantees the result ends with `suffix` exactly once, caps the length at 200 **trimming from the front**. Null/empty/whitespace (or nothing but `global::`) becomes `"Generated"`. |

Does **not** guarantee uniqueness across calls.

### `DiagnosticInfo` / `LocationInfo` — `sealed class`, `IEquatable<T>`

| Member | Contract |
|---|---|
| `new DiagnosticInfo(DiagnosticDescriptor, LocationInfo?, EquatableArray<string>)` | Message args are **strings only**. |
| `new DiagnosticInfo(DiagnosticDescriptor, LocationInfo?, params string[])` | Convenience overload. |
| `Descriptor`, `Location`, `MessageArgs` | Value-compared across all three. |
| `Diagnostic ToDiagnostic()` | Rehydrate at the source-output stage only. |
| `new LocationInfo(string filePath, TextSpan, LinePositionSpan)` | Plain projection; no syntax tree. |
| `Location ToLocation()` | Rebuilds a reportable location. |
| `static LocationInfo? CreateFrom(Location?)` / `CreateFrom(SyntaxNode?)` | `null` for anything not in source — which `Diagnostic.Create` accepts as "no position". |

### `DiagnosticDescriptorFactory` — `sealed class`

| Member | Contract |
|---|---|
| `new DiagnosticDescriptorFactory(string idPrefix, string category)` | e.g. `("SSALG", "SsalKit.Guard")`. |
| `DiagnosticDescriptor Error(int id, string title, string messageFormat, string description, params string[] customTags)` | Id is `{idPrefix}{id:D3}` (invariant culture), `isEnabledByDefault: true`. |
| `DiagnosticDescriptor Warning(...)` | Same, warning severity. |

### `SymbolFacts` — `static class`

| Member | Contract |
|---|---|
| `string ToFqn(ISymbol)` | `global::`-prefixed fully qualified name. |
| `string GetContainingNamespaceName(ISymbol)` | Dotted name, `string.Empty` for the global namespace. |
| `bool IsEffectivelyPublic(INamedTypeSymbol)` | Whole nesting chain is `public`. |
| `bool IsGenericOrNestedInGeneric(INamedTypeSymbol)` | Walks the containing chain — arity alone is not enough. |
| `bool IsAtLeastInternal(Accessibility)` | `public`/`internal`/`protected internal`. `private protected` is **false**; `NotApplicable` is **false**. |
| `bool IsAccessibleFromGeneratedCode(INamedTypeSymbol)` | Whole chain at least internal and not `file`-local. |
| `INamedTypeSymbol? FindGeneratedCodeAccessBlocker(INamedTypeSymbol)` | The offending link, for a message that can name it. |
| `ImmutableArray<DiagnosticInfo> SortForDiagnosticDeterminism(ImmutableArray<DiagnosticInfo>)` | Orders by has-location, file path, span start, id, then joined message args. |

### `AttributeLocations` — `static class`

| Member | Contract |
|---|---|
| `Location GetLocation(AttributeData, ISymbol fallbackSymbol)` | Attribute syntax → symbol's first location → `Location.None`. Never null. Built from the syntax reference's tree/span, never via `GetSyntax()`. |
| `LocationInfo? GetLocationInfo(AttributeData, ISymbol fallbackSymbol)` | Same answer, already cache-safe. **Use this one from a transform stage.** |

### `IsExternalInit`

Empty `internal static class` in `System.Runtime.CompilerServices`, guarded by `#if !SSALKIT_GENERATORS_TOOLKIT_EXCLUDE_ISEXTERNALINIT`. It enables `init` accessors and therefore `record` declarations on `netstandard2.0`.

## 2. Contracts (versioned / immutable)

- **Embedded source contract** — every shipped `.cs` file, enforced by tests over the shipped files:
  1. starts with exactly these three lines: `// <auto-generated/>`, `#pragma warning disable`, `#nullable enable`;
  2. declares only `internal` types;
  3. lives in namespace `SsalKit.Generators.Toolkit` (sole exception: `IsExternalInit.cs`);
  4. parses as **C# 10** (file-scoped namespaces yes; primary constructors, collection expressions no);
  5. declares no `global using`;
  6. never uses `Environment.NewLine`;
  7. every `GetHashCode` accumulator is explicitly `unchecked`;
  8. no conditional compilation except in `IsExternalInit.cs`.
- **These sources compile with the *consumer's* options**, which is why (6) and (7) exist: `<CheckForOverflowUnderflow>true</CheckForOverflowUnderflow>` would otherwise make a hash throw `OverflowException` from a file the consumer cannot edit.
- **A `default` `EquatableArray<T>` is not equal to `Empty`**, and their hashes differ. `Length`, `AsImmutableArray()`, and enumeration treat them alike; only equality distinguishes them. Pick one spelling for "empty" in a pipeline model or the stage reports a change on every run.
- **`DiagnosticInfo.MessageArgs` is fixed to `string`**, not `object?[]`. Formatting happens at the call site (use invariant formats), because an arbitrary object brings reference equality and could root a whole `Compilation`.
- **Roslyn 4.4.0 floor comes from one line:** `SymbolFacts.FindGeneratedCodeAccessBlocker` reads `INamedTypeSymbol.IsFileLocal`. On 4.3.x and older the build fails with `CS1061`. Nothing else in the package references `SymbolFacts`, so dropping that one file (via a `Compile Remove` in a target `BeforeTargets="CoreCompile"`, since `contentFiles` arrive as `Compile` items during restore) is the supported way to pin older Roslyn.
- **Polyfill opt-out symbol:** `SSALKIT_GENERATORS_TOOLKIT_EXCLUDE_ISEXTERNALINIT`. Opting out is always safe — the toolkit's own sources deliberately avoid `record`/`init`, so nothing else breaks.
- **`internal` + fixed namespace means two generator assemblies embedding this package never collide** with each other.

## 3. DO NOT

- **DO NOT let a test project reference this package directly while it also has `[InternalsVisibleTo]` from the generator project.** Both paths bring the same `internal` types (same namespace, same names) into one compilation, and the compiler rejects the ambiguous duplicate. Reach them through `InternalsVisibleTo` only.
- **DO NOT put a raw `Location`, `ISymbol`, `SyntaxNode`, `Compilation`, or plain `ImmutableArray<T>` into a pipeline model.** Use `LocationInfo`, pre-rendered strings, and `EquatableArray<T>`. From a transform stage call `AttributeLocations.GetLocationInfo`, never `GetLocation`.
- **DO NOT mix `default` and `Empty` spellings of `EquatableArray<T>` in one model.** They are unequal, so the stage reports a change every run and the cache is defeated.
- **DO NOT add `record` types, `init` accessors, primary constructors, or collection expressions to the embedded sources.** The contract caps them at C# 10 and forbids `record`/`init` so that opting out of the `IsExternalInit` polyfill stays a free choice. (Consumers of the package are free to use whatever their `LangVersion` allows — this rule is about the shipped files.)
- **DO NOT use `Environment.NewLine` in emitted output.** `IndentedCodeWriter` writes `"\n"` unconditionally so generated files are byte-identical across build machines.
- **DO NOT write a hash accumulator without `unchecked`** in an embedded source.
- **DO NOT declare a `global using` in an embedded source** — it would apply to every file of the consumer's compilation.
- **DO NOT pass `ToCamelCaseIdentifier`'s result straight to a declaration site.** It can be a reserved keyword (`"Class"` → `"class"`). Wrap it: `CSharpNaming.EscapeKeyword(CSharpNaming.ToCamelCaseIdentifier(name))`. `ToPascalCaseIdentifier` needs no such care (every reserved keyword is lower-case).
- **DO NOT feed unsanitized fragments to `JoinIdentifierSegments`** — it joins, it never sanitizes.
- **DO NOT pass a raw fully qualified name to `AddSource`.** Backticks (`` Foo`1 ``) and `+` (nested types) break it; run it through `HintNameSanitizer.Sanitize` — and do not rely on `Sanitize` for uniqueness.
- **DO NOT declare `IsExternalInit` yourself while the polyfill is in.** It is `CS0101`; define the opt-out symbol instead.
- **DO NOT expect Microsoft.CodeAnalysis.Analyzers' release-tracking rules (RS2000–RS2003) to resolve ids built by `DiagnosticDescriptorFactory`.** The id is composed at run time, so the analyzer sees no literal. Suppress `RS2002`/`RS2003` and assert the release files from a test instead.
- **DO NOT add a `Microsoft.CodeAnalysis` package dependency expecting this package to supply it.** It is deliberately not declared, so the consumer keeps its own version pin.

## 4. Diagnostics

This package **reports no diagnostics of its own** — it has no analyzer and no generator. It *helps you author* them:

- `DiagnosticDescriptorFactory` fixes the id format to `{idPrefix}{id:D3}` and `isEnabledByDefault: true`. The SsalKit prefixes built on it are `SSAL` (DependencyInjection), `SSALG` (Guard), `SSALR` (Randomness).
- Because the id is composed at run time, `AnalyzerReleases.Shipped.md` / `AnalyzerReleases.Unshipped.md` can no longer be validated by RS2002/RS2003. Replace them with a test that reads both files and compares `(id, category, severity)` rows against the descriptor table by reflection.

## 5. Canonical snippets

### A cache-safe pipeline model

```csharp
using System;
using System.Collections.Immutable;
using SsalKit.Generators.Toolkit;

internal readonly struct ServiceModel : IEquatable<ServiceModel>
{
    public ServiceModel(string typeName, ImmutableArray<string> interfaceNames)
    {
        TypeName = typeName;
        InterfaceNames = interfaceNames.ToEquatableArray();   // never a raw ImmutableArray
    }

    public string TypeName { get; }

    public EquatableArray<string> InterfaceNames { get; }

    public bool Equals(ServiceModel other) =>
        TypeName == other.TypeName && InterfaceNames.Equals(other.InterfaceNames);

    public override bool Equals(object? obj) => obj is ServiceModel other && Equals(other);

    public override int GetHashCode()
    {
        unchecked
        {
            return (TypeName.GetHashCode() * 31) + InterfaceNames.GetHashCode();
        }
    }
}
```

### Emitting source

```csharp
using SsalKit.Generators.Toolkit;

var writer = new IndentedCodeWriter();
writer.WriteAutoGeneratedHeader();          // add suppressWarnings: true to clear consumer warnings
writer.WriteLine("namespace MyGenerator.Generated;");
writer.WriteLine();

using (writer.Block("internal static class Registration"))
{
    writer.WriteDocLines("<summary>", "Registers everything.", "</summary>");

    using (writer.Block("public static void Register(IServiceCollection services)"))
    {
        writer.WriteLine("services.AddSingleton<ICacheService, CacheService>();");
    }
}

var hintName = HintNameSanitizer.Sanitize(SymbolFacts.ToFqn(typeSymbol));
context.AddSource(hintName, writer.ToString());
```

### Diagnostics through the pipeline

```csharp
using SsalKit.Generators.Toolkit;

internal static class DiagnosticDescriptors
{
    private static readonly DiagnosticDescriptorFactory Factory = new("MINE", "MyGenerator");

    public static readonly DiagnosticDescriptor UnsupportedMember = Factory.Error(
        1,                                   // -> "MINE001"
        "Unsupported member",
        "'{0}' cannot be used because its type '{1}' is not supported",
        "Use one of the supported member types.");
}

// Transform stage: cache-safe, strings only, no Location.
var info = new DiagnosticInfo(
    DiagnosticDescriptors.UnsupportedMember,
    AttributeLocations.GetLocationInfo(attributeData, memberSymbol),
    memberSymbol.Name,
    memberType.ToDisplayString());

// Source-output stage: rehydrate and report.
context.RegisterSourceOutput(diagnostics, static (spc, reported) =>
{
    foreach (var diagnostic in reported)
    {
        spc.ReportDiagnostic(diagnostic.ToDiagnostic());
    }
});
```

### Deciding whether generated code may name a type

```csharp
using SsalKit.Generators.Toolkit;

var blocker = SymbolFacts.FindGeneratedCodeAccessBlocker(typeSymbol);
if (blocker is not null)
{
    var reason = ReferenceEquals(blocker, typeSymbol)
        ? "it is declared '" + blocker.DeclaredAccessibility + "'"
        : "it is nested inside '" + blocker.ToDisplayString() + "'";
    // report, and generate nothing for this type
}
else if (!SymbolFacts.IsGenericOrNestedInGeneric(typeSymbol))
{
    var visibility = SymbolFacts.IsEffectivelyPublic(typeSymbol) ? "public" : "internal";
    // emit
}
```
